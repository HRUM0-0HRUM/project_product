# Telegram-бот для поиска дешевой продуктовой корзины

Бот принимает список продуктов, собирает цены с сайтов магазинов, доставок и показывает, где корзина будет дешевле.

## Команда
- Ердякова М.А.
- Козлова П.Д.
- Скорик Е.В.

## Основные функции
- Приём списка покупок простым текстом в Телеграм боте
- Сравнение итоговой стоимости по магазинам (от дешёвых к дорогим)
- Детализация цен по каждому товару при нажатии на магазин
- Сохранение и загрузка именованных списков
- Подписка на акции и уведомления о скидках
- Настройка магазинов и правил парсинга (для администратора)

## Зависимости
- Python 3.10+
- python-telegram-bot – работа с Telegram API
- aiohttp, beautifulsoup4, lxml – парсинг сайтов
- aiosqlite – хранение данных пользователей
- pydantic – валидация данных
- python-dotenv – чтение токена из .env
- setuptools – сборка проекта

## Запуск
```bash
pip install -r requirements.txt
python main.py
